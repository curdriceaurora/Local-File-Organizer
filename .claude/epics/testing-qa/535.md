# Issue #535: Replace time.sleep with deterministic wait in test_auth_store

## Description

`test_store_refresh_with_zero_ttl_expires_immediately` used `time.sleep(0.01)` for
timing-dependent assertions, making it inherently flaky on slow CI runners.

## File Modified

- `tests/api/test_auth_store.py`

## Resolution

Replaced `time.sleep(0.01)` with direct timestamp manipulation
(`store._refresh["jti-1"] = time.time() - 1`), consistent with the pattern already
used in other tests in the same file (`test_refresh_expiry_cleanup`,
`test_revoked_access_expiry_cleanup`).

Resolved in PR #536.
