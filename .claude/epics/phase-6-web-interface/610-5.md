# Task 610.5: Marketplace HTMX Modernization

**Status**: Not Started | **Priority**: MEDIUM | **Effort**: 1.5 hours

## Problem Statement

Marketplace uses traditional form submissions instead of modern HTMX:
- Install/Update/Uninstall buttons use form POST
- No loading spinners during operations
- No pagination UI (backend supports it, frontend doesn't expose it)
- Plugin details modal not implemented

Result: Marketplace feels outdated compared to rest of UI. No visual feedback during plugin operations.

## Work

### Subtask 1: Convert to HTMX Submissions (45 min)
- [ ] Change "Install" button from `<form>` to `hx-post="/marketplace/install"`
- [ ] Change "Update" button from `<form>` to `hx-post="/marketplace/update"`
- [ ] Change "Uninstall" button from `<form>` to `hx-post="/marketplace/uninstall"`
- [ ] Pass plugin ID in request body instead of form fields
- [ ] Backend endpoints should return updated plugin card HTML

### Subtask 2: Add Loading Spinners (20 min)
- [ ] Add `hx-indicator` attribute to each button
- [ ] Show spinner during operation
- [ ] Disable buttons while operation in progress
- [ ] Hide spinner when operation completes

### Subtask 3: Implement Pagination UI (30 min)
- [ ] Add pagination controls (Previous/Next) at bottom of plugin list
- [ ] Wire to backend pagination: `?page=1&limit=20`
- [ ] Use HTMX to load next page: `hx-get="/marketplace?page=2"`
- [ ] Swap entire plugin list with paginated results
- [ ] Show current page indicator (1/5, etc.)

### Subtask 4: Optional - Plugin Details Modal
- [ ] Click plugin name → opens modal with full details
- [ ] Modal shows: description, author, version, ratings, screenshots
- [ ] Wire to backend GET endpoint returning modal HTML
- [ ] Implement modal close button

## Files to Modify

**Frontend:**
- `src/file_organizer/web/templates/marketplace/index.html`

**Backend:**
- Verify endpoints exist:
  - POST `/marketplace/install` - return updated card
  - POST `/marketplace/update` - return updated card
  - POST `/marketplace/uninstall` - return updated card
  - GET `/marketplace?page={n}` - return paginated list
  - GET `/marketplace/{id}` - return plugin details HTML (optional)

## Acceptance Criteria

- [x] All 3 operations (install/update/uninstall) use HTMX
- [x] Loading spinners visible during operations
- [x] Pagination working and responsive
- [x] Manual test: plugin install flow end-to-end works
- [x] No form posts, all HTMX-based

## Dependencies

- Backend endpoints should already exist or be easy to wire
- Spinner CSS (exists in base.html)
- HTMX already integrated
