# Task 610.2: Add Loading Spinners to Profile Components

**Status**: Not Started | **Priority**: HIGH | **Effort**: 45 minutes

## Problem Statement

8 profile subcomponents load via HTMX but show blank divs during loading:
- `profile/_edit.html`
- `profile/_api_keys.html`
- `profile/_workspaces.html`
- `profile/_team.html`
- `profile/_shared.html`
- `profile/_account_settings.html`
- `profile/_notifications.html`
- `profile/_activity.html`

Result: UX feels sluggish and unresponsive. Users don't know if page is loading.

## Work

### Single Subtask: Add Loading Placeholders (45 min)

For each of the 8 templates:

1. Add loading state placeholder:
```html
<div class="loading-state">
  <div class="spinner"></div>
  <p>Loading...</p>
</div>
```

2. Verify HTMX target div exists and matches route handler

3. Test in browser: spinner shows → content loads → spinner replaced

## Files to Modify

All under `src/file_organizer/web/templates/profile/`:
- `_edit.html`

- `_workspaces.html`
- `_team.html`
