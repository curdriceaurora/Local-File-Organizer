# Task 610.3: Wire Dashboard Metrics (System Pulse Card)

**Status**: Not Started | **Priority**: HIGH | **Effort**: 30 minutes

## Problem Statement

Homepage `index.html` contains a "System Pulse" card with hardcoded metrics:
- Active jobs: 0
- Suggestions: 12
- Rules: 8

Should fetch live data from backend. Currently hardcoded, doesn't reflect actual system state.

## Solution

Add HTMX GET endpoint to fetch real metrics:

### Subtask 1: Create Backend Endpoint (15 min)
- [ ] Add GET `/ui/dashboard/pulse` endpoint in web/router.py or dashboard_routes.py
- [ ] Return JSON: `{active_jobs: int, suggestions: int, rules: int}`
- [ ] Query actual metrics from services

### Subtask 2: Wire Frontend (15 min)
- [ ] Add `hx-get="/ui/dashboard/pulse"` to pulse card div
- [ ] Add `hx-trigger="load"` for immediate fetch on page load
- [ ] Update `hx-swap="innerHTML"` to replace metrics div
- [ ] Test in browser: metrics update on page load

## Files to Modify

**Frontend:**
- `src/file_organizer/web/templates/index.html` - Add hx attributes to pulse card

**Backend:**
- `src/file_organizer/web/router.py` OR new `src/file_organizer/web/dashboard_routes.py`
  - Add GET `/ui/dashboard/pulse` endpoint

## Acceptance Criteria

- [x] Endpoint returns correct JSON structure
- [x] Frontend GET request fires on page load
- [x] Metrics display correctly
- [x] Manual test: hardcoded values gone, real data showing
