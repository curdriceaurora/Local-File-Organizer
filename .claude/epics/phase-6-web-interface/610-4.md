# Task 610.4: Polish Organize Live Views (History & Stats)

**Status**: Not Started | **Priority**: HIGH | **Effort**: 2 hours

## Problem Statement

Two organize dashboard views feel stale and lack visual feedback:

**organize/_history.html:**
- Lists job history
- Auto-fetches on page load
- Missing loading indicator during fetch
- Currently polls every 45 seconds but no visual feedback

**organize/_stats.html:**
- Shows total jobs, active jobs, files organized, success rate
- Missing loading indicator
- Polling interval too slow (45s), should be 10s for live feel
- Should use SSE streaming instead of polling

Result: Users don't know if dashboard is updating. Metrics feel delayed.

## Work

### Subtask 1: Add Loading Indicators (30 min)
- [ ] Add loading spinner to `_history.html` during fetch
- [ ] Add loading spinner to `_stats.html` during fetch
- [ ] Style: subtle spinner with "Updating..." text
- [ ] Hide spinner when content loaded

### Subtask 2: Wire SSE Streaming (60 min)

**For _stats.html:**
- [ ] Use existing SSE endpoint: `/organize/jobs/{id}/events`
- [ ] Subscribe to job updates on page load
- [ ] Update metrics in real-time as SSE events arrive
- [ ] Fall back to polling if SSE unavailable
- [ ] Update interval: 10s instead of 45s

**For _history.html:**
- [ ] Add refresh button with spinner
- [ ] Load history on demand (click) instead of auto-load
- [ ] Use HTMX pagination for large job lists

### Subtask 3: Test & Polish (30 min)
- [ ] Manual test: spinners appear/disappear correctly
- [ ] SSE updates flowing in real-time
- [ ] Responsive on mobile
- [ ] No console errors
