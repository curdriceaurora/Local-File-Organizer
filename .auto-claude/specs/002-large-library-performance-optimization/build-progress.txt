=== INVESTIGATION FINDINGS ===

Existing Architecture:
- SQLAlchemy ORM with repository pattern for database access
- FastAPI routers for REST API endpoints
- In-memory BM25 index rebuilt on each search
- File scanning using Path.rglob() which loads all paths into memory
- Caching infrastructure exists (Redis) but underutilized
- Comprehensive test suite with pytest (307 tests across 334 modules)

Performance Bottlenecks Identified:
1. File scanning uses rglob() which loads all files into memory at once
2. BM25 index rebuilt in-memory on each search, not persisted
3. Missing database indexes for common query patterns (name, mime_type searches)
4. File listing API loads all files before pagination
5. Deduplication hashes files individually without batching
6. No bulk database operations for batch inserts/updates

Patterns to Follow:
- Database migrations: Alembic with naming YYYYMMDD_NNNN_description.py
- Repository pattern: Static methods in src/file_organizer/api/repositories/
- Service pattern: Classes in src/file_organizer/services/
- Caching: Redis with key prefixes (e.g., 'file_metadata:workspace:path')
- Testing: pytest with fixtures in tests/conftest.py
